# 授权边界

<!--
什么时候用：做任何不可逆的动作之前——合并、发布、删除、付费、对外发消息。
整份画像里最值钱的一块。
每条用 `### [硬]` 或 `### [软]` 开头：
  硬 = 每次都必须停下来问，会被摘进常驻层（最多取 3 条）
  软 = 尽量遵守，不必逐次确认
空 = 未启用。此时不要自行假设任何额外限制，也不要假装有。
-->
